# AS-Brain

Центральная AI-платформа AS Group.

## Цель

Создать масштабируемую инфраструктуру, независимую от устройства разработки.

## Архитектура

GitHub
    │
    ▼
Локальная разработка (Mac / Windows)
    │
    ▼
VPS
    │
    ▼
Docker Stack
    ├── Caddy
    ├── n8n
    └── PostgreSQL

## Принципы

- GitHub — главный источник истины.
- Любое устройство может использоваться для разработки.
- VPS используется только для запуска.
- Все изменения проходят через Git.
